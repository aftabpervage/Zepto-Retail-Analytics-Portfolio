# Zepto Sales & Inventory Analysis Dashboard

## End-to-End Data Analytics Project using SQL & Power BI

A complete Data Analytics project built using SQL + Power BI to analyze Zepto product sales, inventory availability, pricing trends, discounts, and category performance.
This project focuses on transforming raw retail data into meaningful business insights through data cleaning, SQL analysis, and interactive Power BI visualizations.

---

# Project Overview

This project combines the power of SQL for data querying & transformation and Power BI for interactive dashboarding to generate actionable insights from retail inventory and sales-related data.

The dashboard helps in understanding:

- Product category performance
- Inventory availability
- Out-of-stock analysis
- Discount trends
- Pricing insights
- Revenue contribution
- Business KPIs

---

# Tools & Technologies Used

- SQL (PostgreSQL) – Data cleaning & analysis
- Power BI – Dashboard creation & visualization
- Power Query – Data transformation
- DAX – KPI calculations & measures
- Excel/CSV Dataset – Source data
